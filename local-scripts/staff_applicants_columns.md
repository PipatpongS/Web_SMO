# คำอธิบายคอลัมน์ในตาราง Staff Applicants (staff_applicants.csv)

ไฟล์นี้เก็บข้อมูลการสมัครงานในส่วนของ **Staff (เจ้าหน้าที่/ทีมงาน)** ที่สมัครผ่านระบบ โดยรายละเอียดของแต่ละคอลัมน์ (Column) มีดังต่อไปนี้:

| ชื่อคอลัมน์ (Column Name) | ประเภทข้อมูล (Type) | คำอธิบาย (Description) |
| :--- | :---: | :--- |
| **id** | String | Firestore Document ID (ใช้ค่าเดียวกับ `line_uid` ในการระบุตัวตน) |
| **line_uid** | String | LINE User ID ที่เป็นค่าเฉพาะตัว (Unique ID) ของบัญชี LINE นั้น ๆ |
| **line_displayName** | String | ชื่อโปรไฟล์ LINE ของผู้สมัครในปัจจุบัน |
| **line_pictureUrl** | String | ลิงก์ URL รูปภาพโปรไฟล์ LINE ของผู้สมัคร |
| **lineId** | String | LINE ID ที่ผู้ใช้กรอกในแบบฟอร์ม เพื่อใช้สำหรับติดต่อส่วนตัว |
| **titlePrefix** | String | คำนำหน้าชื่อ (เช่น นาย, นางสาว, อื่น ๆ) |
| **firstName** | String | ชื่อจริง (ภาษาไทย) |
| **middleName** | String | ชื่อกลาง (ถ้ามี) |
| **lastName** | String | นามสกุล (ภาษาไทย) |
| **nickname** | String | ชื่อเล่น |
| **nationality** | String | สัญชาติ |
| **studentId** | String | รหัสนักศึกษา มจธ. (11 หลัก) ของผู้สมัคร |
| **year** | String/Number | ชั้นปีการศึกษา (เช่น 1, 2, 3, 4) |
| **department** | String | คณะ / ภาควิชา / สาขาที่ผู้สมัครศึกษาอยู่ |
| **email** | String | อีเมลสำหรับติดต่อ |
| **phone** | String | เบอร์โทรศัพท์มือถือ |
| **role1** | String | ฝ่ายของ Staff ที่ต้องการสมัครเป็น**อันดับที่ 1** (First Choice) |
| **role2** | String | ฝ่ายของ Staff ที่ต้องการสมัครเป็น**อันดับที่ 2** (Second Choice) |
| **staffStatus** | String | สถานะการสมัครในปัจจุบัน (เช่น `ส่งใบสมัครเสร็จสิ้น`, `ได้รับการคัดเลือกให้ปฏิบัติงานในตำแหน่ง...`, `ไม่ผ่านการคัดเลือก`) |
| **hasDietaryRestriction** | String | ข้อมูลระบุว่ามีข้อจำกัดด้านอาหารหรือไม่ (เช่น มี, ไม่มี) |
| **dietaryRestriction** | String | รายละเอียดข้อจำกัดด้านอาหาร (เช่น ฮาลาล, เจ, มังสวิรัติ) |
| **dietaryOther** | String | ข้อจำกัดอาหารด้านอื่น ๆ นอกเหนือจากตัวเลือกปกติ |
| **foodAllergyDetails** | String | ข้อมูลการแพ้อาหารเฉพาะอย่าง เช่น แพ้อาหารทะเล, แพ้ถั่ว |
| **hasMedicalCondition** | String | ข้อมูลระบุว่ามีโรคประจำตัวหรือไม่ (เช่น มี, ไม่มี) |
| **medicalConditionDetails** | String | รายละเอียดของโรคประจำตัว (หากระบุว่ามี) |
| **joinActivity** | String | ยืนยันการเข้าร่วมกิจกรรมสัญญากับทีมงาน |
| **pdpaConsent** | Boolean (true/false) | การยอมรับข้อตกลงการคุ้มครองข้อมูลส่วนบุคคล (PDPA) |
| **qr_code** | String | ข้อมูลสำหรับถอดรหัสออกมาเป็น QR Code (โครงสร้างคือ `line_uid:studentId`) |
| **short_code** | String | รหัสสั้น 4 หลัก (เช่น AB12) ที่สุ่มขึ้นมาเพื่อลดความซับซ้อนของ QR Code ในการสแกนเข้างาน |
| **editCount** | Number | จำนวนครั้งที่ทำการแก้ไขข้อมูลใบสมัครผ่านระบบ (จำกัดการแก้ไขไม่เกิน 2 ครั้ง) |
| **note** | String | บันทึกเพิ่มเติม หรือคอมเมนต์เพิ่มเติมจาก Admin หรือระบุเงื่อนไขพิเศษ |
| **createdAt** | Timestamp | วันเวลาที่ส่งใบสมัครเข้าระบบครั้งแรก (ฟอร์แมต ISO 8601 UTC) |
| **updatedAt** | Timestamp | วันเวลาที่ข้อมูลได้รับการแก้ไขหรืออัปเดตครั้งล่าสุด (ฟอร์แมต ISO 8601 UTC) |
