# คำอธิบายคอลัมน์ในตาราง Users (users.csv)

ไฟล์นี้เก็บข้อมูลของผู้เข้าร่วมกิจกรรมทั่วไป (เช่น **นักศึกษาใหม่/ผู้เข้างานทั่วไป**) ที่ลงทะเบียนเข้าร่วมโครงการ โดยรายละเอียดของแต่ละคอลัมน์ (Column) มีดังต่อไปนี้:

| ชื่อคอลัมน์ (Column Name) | ประเภทข้อมูล (Type) | คำอธิบาย (Description) |
| :--- | :---: | :--- |
| **id** | String | Firestore Document ID (ใช้ค่าเดียวกับ `line_uid` ในการระบุตัวตน) |
| **line_uid** | String | LINE User ID ที่เป็นค่าเฉพาะตัว (Unique ID) ของบัญชี LINE |
| **line_displayName** | String | ชื่อโปรไฟล์ LINE ของผู้ลงทะเบียน ณ ตอนที่ลงทะเบียน |
| **line_pictureUrl** | String | ลิงก์ URL รูปภาพโปรไฟล์ LINE ของผู้ลงทะเบียน |
| **titlePrefix** | String | คำนำหน้าชื่อ (เช่น นาย, นางสาว) |
| **firstName** | String | ชื่อจริง (ภาษาไทย) |
| **middleName** | String | ชื่อกลาง (ถ้ามี) |
| **lastName** | String | นามสกุล (ภาษาไทย) |
| **nationality** | String | สัญชาติ |
| **studentIdStatus** | String | สถานะการได้รับรหัสนักศึกษา (เช่น `ได้รับรหัสนักศึกษาแล้ว`, `ยังไม่ได้รับรหัสนักศึกษา`) |
| **studentId** | String | รหัสนักศึกษา มจธ. (11 หลัก) หรือรหัสจำลองชั่วคราว |
| **program** | String | โครงการ/หลักสูตรที่ศึกษา (เช่น โครงการภาษาไทย, โครงการนานาชาติ) |
| **department** | String | คณะ / ภาควิชา / สาขาที่ลงทะเบียนเรียน |
| **email** | String | อีเมลสำหรับติดต่อ |
| **phone** | String | เบอร์โทรศัพท์มือถือ |
| **is_verified** | Boolean (true/false) | สถานะยืนยันตัวตนว่าข้อมูลถูกต้องและเป็นนักศึกษาจริงจากแอดมิน |
| **is_shirt_ordered** | Boolean (true/false) | สถานะการสั่งจองเสื้อกิจกรรม |
| **shirtSize** | String | ขนาดไซส์เสื้อที่สั่งจอง (เช่น S, M, L, XL, 2XL) |
| **shirt_received_at** | Timestamp | วันเวลาที่สแกนรับเสื้อจริงที่หน้างาน (ว่างเปล่า หากยังไม่ได้รับ) |
| **joinActivity** | String | สถานะการยืนยันเข้าร่วมงาน (เช่น เข้าร่วม, ไม่เข้าร่วม) |
| **pdpaConsent** | Boolean (true/false) | การยอมรับข้อตกลงคุ้มครองข้อมูลส่วนบุคคล (PDPA) |
| **hasDietaryRestriction** | String | ข้อมูลระบุว่ามีข้อจำกัดด้านอาหารหรือไม่ (เช่น มี, ไม่มี) |
| **dietaryRestriction** | String | รายละเอียดข้อจำกัดด้านอาหาร (เช่น ฮาลาล, เจ, มังสวิรัติ) |
| **dietaryOther** | String | ข้อจำกัดอาหารอื่นๆ เพิ่มเติมที่ไม่ได้อยู่ในตัวเลือกปกติ |
| **foodAllergyDetails** | String | ข้อมูลรายละเอียดการแพ้อาหารเฉพาะตัว |
| **hasMedicalCondition** | String | ข้อมูลระบุว่ามีโรคประจำตัวหรือไม่ (เช่น มี, ไม่มี) |
| **medicalConditionDetails** | String | รายละเอียดของโรคประจำตัว (หากระบุว่ามี) |
| **qr_code** | String | ข้อมูลต้นฉบับในการใช้ถอดรหัสออกมาเป็น QR Code |
| **short_code** | String | รหัสสั้น 4 หลักสำหรับลดความยาวในการสแกนคิวอาร์โค้ด |
| **checkin_day1_morning** | Timestamp | วันเวลาสแกนเข้างานรอบเช้าในวันที่ 1 (ฟอร์แมต ISO 8601 UTC) |
| **checkin_day1_afternoon** | Timestamp | วันเวลาสแกนเข้างานรอบบ่ายในวันที่ 1 (ฟอร์แมต ISO 8601 UTC) |
| **checkin_day2_morning** | Timestamp | วันเวลาสแกนเข้างานรอบเช้าในวันที่ 2 (ฟอร์แมต ISO 8601 UTC) |
| **checkin_day2_afternoon** | Timestamp | วันเวลาสแกนเข้างานรอบบ่ายในวันที่ 2 (ฟอร์แมต ISO 8601 UTC) |
| **editCount** | Number | จำนวนครั้งที่ทำการแก้ไขข้อมูลของตนเองในระบบ (จำกัดไม่เกิน 2 ครั้ง) |
| **note** | String | บันทึกช่วยจำเพิ่มเติมจาก Admin (เช่น "รอบพิเศษ") |
| **createdAt** | Timestamp | วันเวลาที่สแกนลงทะเบียนครั้งแรก (ฟอร์แมต ISO 8601 UTC) |
| **updatedAt** | Timestamp | วันเวลาที่ข้อมูลได้รับการอัปเดตครั้งล่าสุด (ฟอร์แมต ISO 8601 UTC) |
