# วิธีการแก้ไขสถานะใบสมัคร Staff ใน Firebase (Firestore)

ในการทดสอบหรือปรับเปลี่ยนสถานะของผู้ลงสมัคร Staff ในระบบผ่าน Firebase ให้ทำตามรายละเอียดดังนี้ครับ:

## 📁 ข้อมูลตำแหน่งที่ต้องแก้ไขใน Firebase Console
1. เข้าไปยัง **Firebase Console** -> เลือกโปรเจกต์ของคุณ
2. ไปที่เมนู **Build** -> **Firestore Database**
3. ค้นหาคอลเลกชัน (Collection) ชื่อ: **`staff_applicants`**
4. เลือกเอกสาร (Document) ของผู้ใช้งานที่ต้องการแก้ไข (โดยจะใช้ ID เป็น `userId` ของ LINE)
5. แก้ไขฟิลด์ (Field) ชื่อ: **`staffStatus`** (ประเภทข้อมูลเป็น `string`)

---

## ⚙️ ค่าของฟิลด์ `staffStatus` ที่ระบบรองรับ

คุณสามารถลองเปลี่ยนค่าในฟิลด์ **`staffStatus`** เป็นค่าต่างๆ ด้านล่างนี้เพื่อดูการแสดงผลบนหน้าจอ Profile:

### 1. สถานะ: ส่งใบสมัครเสร็จสิ้น (รอดำเนินการ)
* **ค่าที่ต้องระบุใน Firebase:** `ส่งใบสมัครเสร็จสิ้น` (หรือหากเป็นค่าว่างเปล่า ระบบจะดีฟอลต์เป็นสถานะนี้เช่นกัน)
* **การแสดงผลบนเว็บ:** แสดงกรอบสีฟ้าอ่อนพร้อมสัญลักษณ์ 📋 และข้อความ "ส่งใบสมัครเสร็จสิ้น"

### 2. สถานะ: ผ่านการคัดเลือก (ได้รับการตอบรับ)
* **ค่าที่ต้องระบุใน Firebase:** 
  * `ได้รับการคัดเลือกให้ปฏิบัติงานในตำแหน่ง [ชื่อฝ่าย]`
  *(พิมพ์ข้อความข้างต้นให้ถูกต้อง พร้อมเว้นวรรค 1 ช่องหลังคำว่า "ตำแหน่ง" แล้วตามด้วยชื่อฝ่าย)*
* **ตัวอย่างค่าที่ระบุได้:**
  * `ได้รับการคัดเลือกให้ปฏิบัติงานในตำแหน่ง ฝ่ายกิจกรรม`
  * `ได้รับการคัดเลือกให้ปฏิบัติงานในตำแหน่ง ฝ่ายพยาบาล`
  * `ได้รับการคัดเลือกให้ปฏิบัติงานในตำแหน่ง ฝ่ายสถานที่และสวัสดิการ`
  * `ได้รับการคัดเลือกให้ปฏิบัติงานในตำแหน่ง ประชาสัมพันธ์`
* **การแสดงผลบนเว็บ:** แสดงกรอบสีเขียวอ่อนพร้อมสัญลักษณ์ ✅ และมีปุ่ม **"ดูรายละเอียดฝ่าย"** (View Role Details) ปรากฏขึ้นมาด้านล่างข้อความ เพื่อให้ผู้ใช้สามารถกดดูรายละเอียดวันเวลาและหน้าที่ของฝ่ายนั้นๆ ได้

### 3. สถานะ: ไม่ผ่านการคัดเลือก
* **ค่าที่ต้องระบุใน Firebase:** `ไม่ผ่านการคัดเลือก`
* **การแสดงผลบนเว็บ:** แสดงกรอบสีแดงอ่อนพร้อมสัญลักษณ์ ❌ และข้อความ "ไม่ผ่านการคัดเลือก"

---

> [!NOTE]
> **หมายเหตุสำหรับการทดสอบ:** 
> หลังจากกด Save ค่าบน Firebase แล้ว ให้ลองรีเฟรชหน้า Profile บนบราวเซอร์เพื่อดึงข้อมูลล่าสุดครับ เนื่องจากระบบมีการเก็บ Cache ข้อมูลใน LocalStorage เพื่อความเร็วในการโหลด หากข้อมูลไม่เปลี่ยนทันที แนะนำให้ลองเปิดหน้าเว็บในโหมดหน้าต่างไม่ระบุตัวตน (Incognito) หรือกดเคลียร์ Cache ของเว็บบราวเซอร์ครับ
